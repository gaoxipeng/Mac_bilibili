## 更新内容

- 智能防遮挡合并为三个选项：关、防挡脸、防挡人形；关闭时停止识别并清除遮罩，兼容原有开关偏好。
- 新增整个人形轮廓的弹幕避让，改进侧脸、头发、后脑及下巴区域的轮廓覆盖，减少矩形裁切。
- 防遮挡采样频率由每秒 8 帧提升至最多 12 帧，分析输入宽度由 320 提升至 512 像素，并改善缩小采样质量。
- 重写防遮挡三态胶囊开关：白色小滑块与外层轨道保持间隙，支持按住变透明、左右拖动和平滑切换动画。
- 移除返回操作时标题向左飘走的动画。

## 系统要求

- Apple Silicon Mac（arm64）
- macOS 27.0 或更高版本

## 安装

下载并解压 `bilibili-20261017-macOS.zip`，将 `bilibili.app` 拖入“应用程序”。如需使用终端安装，先退出正在运行的 bilibili，再执行：

```sh
cd ~/Downloads
ditto -x -k bilibili-20261017-macOS.zip bilibili-20261017
ditto bilibili-20261017/bilibili.app /Applications/bilibili.app
```

此版本沿用 ad-hoc 签名，未经 Apple Developer ID 公证。如果 macOS 阻止打开，可在“系统设置 → 隐私与安全性”中允许打开；确认下载来源为本 Release 后，也可执行：

```sh
xattr -dr com.apple.quarantine /Applications/bilibili.app
open /Applications/bilibili.app
```
