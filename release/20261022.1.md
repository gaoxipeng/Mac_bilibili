## 更新内容

- 恢复原先的人形检测方式：使用高质量人形分割、逐帧创建识别请求，并让 Vision 自动选择计算设备，恢复使用神经引擎的可能性。
- 保留输入图像检查、IOSurface 缓冲区、识别任务串行化，以及切换视频后丢弃旧识别结果的保护。
- 修复启动时钥匙串反复询问电脑密码：登录恢复、凭证更新和退出登录均采用非交互访问，不会在后台弹出授权窗口。
- 新登录条目采用版本化存储。旧条目若无法静默访问，将提示重新登录哔哩哔哩一次；登录信息仍只保存在本机钥匙串，不写入明文文件。
- 发布安装包改用固定 Apple Development 证书签名，避免 ad-hoc 签名每次变化造成钥匙串身份失效；增加可复用的签名打包脚本。

## 验证与限制

验证旧签名条目无法读取时可静默恢复、新登录条目保存、跨进程读取、相同证书签名的不同构建读取，以及退出登录不会恢复旧凭证。恢复系统自动选择设备后，之前的神经引擎崩溃仍需通过长时间播放继续观察。

## 系统要求

- Apple Silicon Mac（arm64）
- macOS 27.0 或更高版本

## 安装

下载并解压 `bilibili-20261022.1-macOS.zip`，先退出 bilibili，再将 `bilibili.app` 拖入“应用程序”。终端安装命令：

```sh
cd ~/Downloads
ditto -x -k bilibili-20261022.1-macOS.zip bilibili-20261022.1
ditto bilibili-20261022.1/bilibili.app /Applications/bilibili.app
```

此版本使用 Apple Development 证书签名，尚未经过 Developer ID 公证。若 macOS 阻止打开，可在“系统设置 → 隐私与安全性”中允许打开；确认下载来源为本 Release 后，也可执行：

```sh
xattr -dr com.apple.quarantine /Applications/bilibili.app
open /Applications/bilibili.app
```

如果旧版登录信息无法迁移，请在应用内重新登录哔哩哔哩一次。
