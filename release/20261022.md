## 更新内容

- 针对 macOS 27.2 下智能防遮挡识别期间的闪退作兼容性修复：人形分割显式选择支持的 GPU，必要时选择 CPU，绕开崩溃日志中的神经引擎执行路径。
- 加强输入图像长度、尺寸和行跨度检查，使用支持 Metal 的 IOSurface 图像缓冲区，并保持输入和识别请求存活至推理完成。
- 串行执行不同播放器的识别任务，复用当前视频的识别请求，并及时释放逐帧临时对象。
- 修复切换视频或防遮挡模式时，旧任务可能回写轮廓跟踪状态的问题；补充识别错误日志。

## 验证情况

Release 构建、40 帧合成图像的实际 Vision 推理，以及无效输入、模式切换、重置和图像尺寸切换检查通过。原日志中的长时间播放闪退尚未复现，仍需继续观察。

## 系统要求

- Apple Silicon Mac（arm64）
- macOS 27.0 或更高版本

## 安装

下载并解压 `bilibili-20261022-macOS.zip`，将 `bilibili.app` 拖入“应用程序”。使用终端安装时，先退出正在运行的 bilibili，再执行：

```sh
cd ~/Downloads
ditto -x -k bilibili-20261022-macOS.zip bilibili-20261022
ditto bilibili-20261022/bilibili.app /Applications/bilibili.app
```

此版本沿用 ad-hoc 签名，未经 Apple Developer ID 公证。如果 macOS 阻止打开，可在“系统设置 → 隐私与安全性”中允许打开；确认下载来源为本 Release 后，也可执行：

```sh
xattr -dr com.apple.quarantine /Applications/bilibili.app
open /Applications/bilibili.app
```
