## 更新内容

- 调整首页按钮：从其他页面点击时先切回首页；已在首页时点击则触发刷新并回到列表顶部。
- 从首页进入视频或用户详情后，首次点击首页只返回首页，再次点击才刷新。
- 刷新过程中再次点击首页不会重复发送刷新请求。

## 系统要求

- Apple Silicon Mac（arm64）
- macOS 27.0 或更高版本

## 安装

下载并解压 `bilibili-20261023-macOS.zip`，先退出 bilibili，再将 `bilibili.app` 拖入“应用程序”。终端安装命令：

```sh
cd ~/Downloads
ditto -x -k bilibili-20261023-macOS.zip bilibili-20261023
ditto bilibili-20261023/bilibili.app /Applications/bilibili.app
```

安装包保留固定 Apple Development 证书签名，尚未经过 Developer ID 公证。若 macOS 阻止打开，可在“系统设置 → 隐私与安全性”中允许打开；确认下载来源为本 Release 后，也可执行：

```sh
xattr -dr com.apple.quarantine /Applications/bilibili.app
open /Applications/bilibili.app
```

从旧版升级时，如果历史钥匙串权限无法迁移，需要在应用内重新登录哔哩哔哩一次。
