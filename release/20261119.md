## 更新内容

- 播放控制栏新增实际清晰度显示和切换，支持当前可用画质档位。
- 清晰度切换预加载新画面并保留原音频输出，移除持续变速校正，减少切换中断和切换后忽快忽慢。
- 清晰度、倍速和选集统一液态玻璃圆角弹窗、悬停与选中配色；倍速改为竖排，控制栏按钮放大并统一间距。
- 选集移至清晰度左侧，显示序号、完整标题和时长；支持上下箭头滚动，隐藏滚动条，鼠标停留时保持弹窗打开。
- 修正在看人数解析和展示，移至发布时间之前，支持每 30 秒自动刷新。
- 修复弹幕设置滑块交互，保留原生外观；字号上限提高至 250%，修正高档位字号提前饱和的问题。

## 系统要求

- Apple Silicon Mac（arm64）
- macOS 27.0 或更高版本

## 安装

下载并解压 `bilibili-20261119-macOS.zip`，先退出 bilibili，再将 `bilibili.app` 拖入“应用程序”。终端安装命令：

```sh
cd ~/Downloads
ditto -x -k bilibili-20261119-macOS.zip bilibili-20261119
ditto bilibili-20261119/bilibili.app /Applications/bilibili.app
```

安装包保留固定 Apple Development 证书签名，尚未经过 Developer ID 公证。若 macOS 阻止打开，可在“系统设置 → 隐私与安全性”中允许打开；确认下载来源为本 Release 后，也可执行：

```sh
xattr -dr com.apple.quarantine /Applications/bilibili.app
open /Applications/bilibili.app
```

从旧版升级时，如果历史钥匙串权限无法迁移，需要在应用内重新登录哔哩哔哩一次。
