## 更新内容

- 选集、清晰度和倍速弹窗根据实际内容动态调整宽度，减少多余留白，避免清晰度文字显示不全。
- 选集宽度同时考虑标题和时长，长标题在最大宽度内自动换行。
- 弹窗位置按实际宽度对齐对应按钮，并限制在播放器范围内。

## 系统要求

- Apple Silicon Mac（arm64）
- macOS 27.0 或更高版本

## 安装

下载并解压 `bilibili-20261120-macOS.zip`，先退出 bilibili，再将 `bilibili.app` 拖入“应用程序”。终端安装命令：

```sh
cd ~/Downloads
ditto -x -k bilibili-20261120-macOS.zip bilibili-20261120
ditto bilibili-20261120/bilibili.app /Applications/bilibili.app
```

安装包保留固定 Apple Development 证书签名，尚未经过 Developer ID 公证。若 macOS 阻止打开，可在“系统设置 → 隐私与安全性”中允许打开；确认下载来源为本 Release 后，也可执行：

```sh
xattr -dr com.apple.quarantine /Applications/bilibili.app
open /Applications/bilibili.app
```

从旧版升级时，如果历史钥匙串权限无法迁移，需要在应用内重新登录哔哩哔哩一次。
