## 更新内容

- 收紧窗口和全屏播放时弹幕上下行距。
- 显示区域细分为 10%～100% 共 10 档，并将旧设置映射到最接近的新档位。
- 控制栏按钮间距统一增至 22 点。
- 两侧时间区域按视频时长预留固定宽度，避免秒数、分钟和小时变化时挤动相邻控件。

## 系统要求

- Apple Silicon Mac（arm64）
- macOS 27.0 或更高版本

## 安装

下载并解压 `bilibili-20261121-macOS.zip`，先退出 bilibili，再将 `bilibili.app` 拖入“应用程序”。终端安装命令：

```sh
cd ~/Downloads
ditto -x -k bilibili-20261121-macOS.zip bilibili-20261121
ditto bilibili-20261121/bilibili.app /Applications/bilibili.app
```

安装包保留固定 Apple Development 证书签名，尚未经过 Developer ID 公证。若 macOS 阻止打开，可在“系统设置 → 隐私与安全性”中允许打开；确认下载来源为本 Release 后，也可执行：

```sh
xattr -dr com.apple.quarantine /Applications/bilibili.app
open /Applications/bilibili.app
```

从旧版升级时，如果历史钥匙串权限无法迁移，需要在应用内重新登录哔哩哔哩一次。
