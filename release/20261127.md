## 系统要求

- Apple Silicon Mac（arm64）
- macOS 27.0 或更高版本

## 安装

下载并解压 `bilibili-20261127-macOS.zip`，先退出 bilibili，再将 `bilibili.app` 拖入“应用程序”。终端安装命令：

```sh
cd ~/Downloads
ditto -x -k bilibili-20261127-macOS.zip bilibili-20261127
ditto bilibili-20261127/bilibili.app /Applications/bilibili.app
```

安装包保留固定 Apple Development 证书签名，尚未经过 Developer ID 公证。若 macOS 阻止打开，可在“系统设置 → 隐私与安全性”中允许打开；确认下载来源为本 Release 后，也可执行：

```sh
xattr -dr com.apple.quarantine /Applications/bilibili.app
open /Applications/bilibili.app
```
